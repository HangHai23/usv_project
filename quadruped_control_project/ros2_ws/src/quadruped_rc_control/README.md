# 前进时四个舵机的角度控制逻辑

前进时，公共相位 `phase` 从0向1递增，达到1后回到0，重复循环。
四个舵机按各自的相位偏移、安装方向计算角度。

| 足部 | 输出通道 | 相位偏移 | 方向 |
|---|---:|---:|---:|
| 左前 | 1 | 0.0 | +1 |
| 左后 | 2 | 0.5 | +1 |
| 右前 | 3 | 0.5 | -1 |
| 右后 | 4 | 0.0 | -1 |

左前与右后同相，左后与右前同相，两组相差半周期。
右侧方向为-1，因此同相的对角腿角度变化方向相反。

## 单个舵机的角度计算

默认中位87°、摆幅±20°。每条腿的局部相位和摆动值为：

```python
p = (phase + phase_offset) % 1.0

if p < 0.7:
    # 前70%周期：摆动值从+1缓慢降到-1。
    stroke = 1.0 - 2.0 * p / 0.7
else:
    # 后30%周期：摆动值从-1快速升到+1。
    stroke = -1.0 + 2.0 * (p - 0.7) / 0.3

angle = round(87.0 + direction * 20.0 * stroke)
```

方向为+1的左侧舵机：107° → 67°慢摆，再67° → 107°快摆。
方向为-1的右侧舵机：67° → 107°慢摆，再107° → 67°快摆。

## 四个舵机的计算公式

令 `s(p)` 表示上述 `stroke` 分段函数：

```python
left_front  = round(87 + 20 * s(phase % 1.0))
left_rear   = round(87 + 20 * s((phase + 0.5) % 1.0))
right_front = round(87 - 20 * s((phase + 0.5) % 1.0))
right_rear  = round(87 - 20 * s(phase % 1.0))
```

一轮前进周期中的角度示例（单位：度）：

| 公共相位 | 左前 / 通道1 | 左后 / 通道2 | 右前 / 通道3 | 右后 / 通道4 |
|---:|---:|---:|---:|---:|
| 0.00 | 107 | 78 | 96 | 67 |
| 0.25 | 93 | 74 | 100 | 81 |
| 0.50 | 78 | 107 | 67 | 96 |
| 0.75 | 74 | 93 | 81 | 100 |
| 1.00（回到0） | 107 | 78 | 96 | 67 |
